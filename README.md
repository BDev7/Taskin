## Overview

TaskIN is an on-demand home services platform designed to simplify how users discover and connect with service professionals. The application combines a Flutter-based mobile interface with backend services, structured data management, and notification capabilities to provide a convenient service-booking experience.

## Key Features

- **On-Demand Services:** Helps users discover professionals for everyday service requirements.
- **Verified Professionals:** Supports a marketplace of verified service providers.
- **Cross-Platform Development:** Built with Flutter for a consistent mobile experience.
- **Backend Integration:** Node.js-based backend for application logic and API communication.
- **Database Management:** PostgreSQL for structured and reliable data storage.
- **Push Notifications:** Supabase Cloud Messaging integration for timely notifications.
- **User-Centric Design:** Focuses on making service discovery and interaction convenient.

## Application Workflow

1. Users explore available services.
2. Users discover professionals suited to their requirements.
3. Users interact with the platform to access relevant services.
4. Notifications provide timely updates and information.

## Architecture

TaskIN follows a layered application approach:

- **Mobile Layer:** Flutter-based user interface and application logic.
- **Backend Layer:** Node.js services and API communication.
- **Data Layer:** PostgreSQL for structured data persistence.
- **Notification Layer:** Supabase Cloud Messaging integration.
